RESEARCHHUB AI v2 — PERSONAL PROTOTYPE

Included:
- Dashboard with shortcuts to AI assistants, academic search, citation, and writing tools.
- Paper Library, Reference Organizer, Research Notes.
- Research workflow guide.
- Responsive layout and basic PWA files for later HTTPS hosting / Android installation.

IMPORTANT LIMITATIONS:
- This is a local prototype, not a deployed public website or Play Store app.
- External services open in separate tabs; they are not directly integrated.
- Paper/Reference/Notes data uses browser localStorage on this device/browser only.
- No cloud sync, login, automatic backup, or PDF upload/reading is included.
- Back up important work separately. Clearing browser data may erase locally saved entries.
- Use official sites and review their privacy/age requirements. Do not share sensitive personal information.
- AI-generated citations and summaries must be checked against original sources.
To install as an Android PWA: host these files on an HTTPS website, open that URL in Chrome on Android, then use the browser menu > Install app / Add to Home screen.
